# IoT 기반 스마트 알람 시계 (Smart Alarm Clock)

아두이노 Uno R4 WiFi와 FSM(상태 제어 기법) 기반의 비동기 제어 로직을 활용하여 구현한 스마트홈 IoT 알람 시계입니다.
NTP 서버 동기화를 통한 정확한 시간 안내는 물론, 공공 API를 활용하여 날씨와 미세먼지 정보를 수집한 뒤 자체 조합형 음성 브리핑과 모바일 푸시 알림을 제공합니다.

## 1. 주요 기능

* 실시간 기상 브리핑 시스템
  * 단일 버튼을 짧게 누를 시 현재 시간, 날씨, 기온, 미세먼지 정보를 음성과 화면으로 브리핑
* 스마트 푸시 알림 연동
  * 브리핑 정보를 사용자 스마트폰으로 즉각 전송 (Pushsafer API 활용)
* 알람 설정 모드 (FSM 기반 다중 제어)
  * 버튼을 3초 이상 길게 누르면 알람 설정 모드 진입
  * 단일 버튼 하나로 시/분 조절 모드 전환 및 값 증가 연산 처리
* 오프라인 멈춤 방지 (네트워크 예외 처리)
  * WiFi 재연결 시도 중에도 시계 카운팅 및 버튼 조작 메인 루프가 멈추지 않도록 비동기 설계 적용

## 2. 기술 스택 및 하드웨어 구성

### 소프트웨어 및 라이브러리
* Language: C++ (Arduino IDE)
* Network: HTTP(S), NTP (WiFiS3, NTPClient)
* Data Parsing: ArduinoJson (OpenWeatherMap REST API 연동)
* Display Control: U8g2 (Software SPI 방식 적용)
* Notification: Pushsafer 연동

### 하드웨어 부품
* MCU: Arduino Uno R4 WiFi (네트워크 통신과 메인 로직 처리의 안정성 확보를 위해 채택)
* Display: 128x64 그래픽 LCD (ST7920)
* Audio: DFPlayer Mini & 스피커 (SoftwareSerial 통신 기반 제어)
* Input: Tact Switch (단일 버튼)

## 3. 핵심 트러블슈팅 및 최적화

### (1) 단일 버튼 다중 제어를 위한 FSM(상태 머신) 패턴 적용
* 문제: 하나의 버튼으로 '음성 브리핑 재생', '알람 설정 모드 진입', '시/분 조절', '알람 모드 종료'를 모두 제어해야 하는 상황.
* 해결: `millis()` 타이머 함수를 활용하여 버튼이 눌린 시간(Press Duration)을 측정하는 상태 제어 로직 구축. 1초 미만(짧게), 3초 이상(길게) 등의 조건에 따라 기능을 분기하고 물리적 노이즈(디바운싱)를 소프트웨어적으로 제거함.

### (2) 저사양 기기에서의 음성 출력 딜레이 최적화
* 문제: 외부 클라우드의 실시간 TTS(음성 변환) API를 사용할 경우, 소형 MCU의 램(RAM) 부족 및 오디오 스트림 해독 과부하로 인해 출력 지연 현상 발생.
* 해결: 출력 도메인(시간, 날씨 단어, 숫자)이 제한적이라는 점에 착안, 140여 개의 단어를 분할 녹음하여 SD카드에 저장. 시간 및 기상 변수에 맞춰 필요한 오디오 파일의 번호를 수학적으로 계산하고 딜레이 없이 이어서 재생(Concatenative Synthesis 방식)하는 알고리즘을 구현하여 지연 시간 없는(Zero-latency) 음성 출력 달성.

### (3) API 응답 문자열 파싱 최적화
* 문제: OpenWeatherMap API에서 반환하는 한국어 기상 정보 텍스트("온흐림", "실 비")가 실생활에서 사용하는 어색한 단어로 출력되는 현상 발견.
* 해결: JSON 역직렬화 직후, 문자열 조건문을 통해 "약간 흐림", "약한 비" 등으로 보정하여 출력하는 데이터를 전처리 과정을 거쳐 사용자 경험(UX) 개선.
